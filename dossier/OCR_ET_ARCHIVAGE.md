# Extraction de texte, index et conservation des preuves

## Extraction effectuée le 10 novembre 2026

- PDF V9 intégral : **81 pages sur 81** contiennent déjà un texte sélectionnable; extraction native par page (non OCR de reconstruction).
- Les autres versions PDF et Word disponibles ont été extraites dans un corpus texte séparé, avec un registre des sources.
- Paquet de travail **`COSTA_CHAMBLY_OCR_INDEX_COMPLET_V10.zip`**, index par page et registres CSV.
- Inventaire SHA-256 sur les octets présents dans les archives existantes : **59 photographies de site, 17 vidéos, 2 justificatifs photographiés**.
- Les 17 vidéos ne sont pas des transcriptions verbales. Les légendes enregistrent des scènes observables ; elles ne certifient pas la cause ou l'auteur des dommages.
- Copies de formulaires policiers manuscrits : transcription intégrale **non certifiée** ; vérifier manuellement les noms, heures et numéros sur l'original. Éviter d'inventer une lecture OCR de l'écriture.

## Préservation

- Distinguer les **originaux**, les **copies de consultation**, les **captures de vidéos**, les **notes d'interprétation** et les **rapports synthétiques**.
- Garder les noms source, taille, empreinte SHA-256, date de réception et chaîne de garde.
- Ne pas remplacer les preuves par des versions recompressées ni « retoucher » les captures.
- Des fichiers d'origine peuvent contenir des images de tiers, des coordonnées et des documents nominatifs. Ne pas publier ces originaux dans le dépôt GitHub public.
- Les archives sources de cette compilation sont `R2NETTE_Costa_Chambly_Pieces_Originales_V8.zip` et `R2NETTE_Costa_Chambly_Pieces_Supplementaires_V9.zip`. Elles sont conservées séparément de GitHub.
- L'ajout dans un espace de dossiers juridiques sécurisé requiert un compte autorisé. GitHub ne constitue pas en soi une gestion de preuve avec chaîne de garde certifiée.

## Reprise

Importer l'archive documentaire locale V10 et les deux archives sources dans l'espace documentaire autorisé, puis enregistrer l'emplacement et les empreintes dans le journal sans insérer d'identifiants privés sur GitHub.

Les index conservés ici peuvent évoluer sans détruire l'historique d'origine des documents.
